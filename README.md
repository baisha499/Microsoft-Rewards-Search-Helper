# Microsoft-Rewards-Search-Helper

本程序旨意帮助用户快速刷取Microsoft Rewards的每日搜索积分

首先先

```cmd
git clone https://github.com/baisha499/Microsoft-Rewards-Search-Helper
```

然后确保安装了python

之后运行

```cmd
python -m pip install -r requirements.txt
```


最后双击pyw文件享受！

软件写的非常简洁明了，不会用的可能就是啥子了

本程序由deepseek辅助编写

# 这个程序中的搜索5次为会员，15次为银牌，20次为金牌，当然你可以自定义

# 本程序可以把窗口挂在后台刷，前台可以打游戏，刷完了会有窗口提示

# 驱动可自行下载，也可打开app进行自动更新
[edge驱动下载地址](https://developer.microsoft.com/zh-cn/microsoft-edge/tools/webdriver/?form=MA13LH&cs=1026196607)

[chrome驱动（114以前）](https://chromedriver.storage.googleapis.com/index.html)

[chorme驱动最新版（官网提供）](https://googlechromelabs.github.io/chrome-for-testing/)

谷歌查看版本号方式（输入以下信息）：
