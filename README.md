# Microsoft-Rewards-Search-Helper

本程序旨意帮助用户快速刷取Microsoft Rewards的每日搜索积分

首先先

```cmd
git clone https://github.com/baisha499/Microsoft-Rewards-Search-Helper
```

然后确保安装了python

之后运行

```cmd
python -m pip install -r requirements.txt
```


最后双击pyw文件享受！

软件写的非常简洁明了，不会用的可能就是啥子了

本程序由deepseek辅助编写

#这个程序中的搜索20次和30次并不对应金银铜牌会员搜索次数！！！金为20次，银为15次，铜不知道，应该是10次

#本程序可以把窗口挂在后台刷，前台可以打游戏，刷完了会有窗口提示
